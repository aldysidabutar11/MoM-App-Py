# ===========================================================================
# MoM-IGD - Phase 1 RUNTIME dependencies, exact versions.
#
# Target interpreter: official Python 3.12 (python.org, per-user install).
# NOT the Microsoft Store shim, NOT Python 3.14.
#
# Install:
#     py -3.12 -m venv .venv
#     .venv\Scripts\python.exe -m pip install -r requirements.txt
#
# Refresh (after deliberately changing a direct dependency in pyproject.toml):
#     .venv\Scripts\python.exe -m pip install --upgrade <package>
#     .venv\Scripts\python.exe -m pip freeze --exclude-editable
#   then move dev-only lines into requirements-dev.txt and keep this file to the
#   runtime closure. `tests/test_offline_policy.py` fails if a cloud SDK or a
#   deferred AI/audio dependency appears in the environment, and
#   `tests/test_cli.py` fails if any line here is not pinned with `==`.
#
# Hash-pinned offline wheelhouse creation is deferred to Phase 11.
# ---------------------------------------------------------------------------
# DIRECT (6): fastapi, uvicorn, psutil, pywebview, sounddevice, cryptography
# Everything else below is a transitive dependency of those six.
#
# `sounddevice` arrived with Phase 2 (offline audio capture). It is the only
# audio dependency: it wraps PortAudio/WASAPI for input, and `RawInputStream`
# hands us raw bytes, so NumPy is not required. WAV files are written with the
# standard-library `wave` module and checksums with `hashlib`, so no codec,
# resampler or DSP library is needed either.
#
# `cryptography` arrived with Phase 3 (voiceprint encryption at rest). It supplies
# AES-256-GCM, which the standard library does not have. It is used for exactly
# that: authenticated encryption of biometric templates. Notes:
#   - the master key is protected by Windows DPAPI, reached through `ctypes` and
#     `crypt32.dll`, so pywin32 is NOT required for two API calls;
#   - the wheel is prebuilt (cp311-abi3-win_amd64), so no compiler is involved;
#   - it makes no network call, and nothing in this project asks it to;
#   - `cffi`/`pycparser` were already in the closure, so this adds exactly one
#     distribution.
# Base64 is NOT an alternative and must never be used as one (ADR-0010).
#
# Deliberately ABSENT and forbidden:
#   - any cloud SDK (google-genai, openai, anthropic, boto3, azure-*, ...)
#   - any AI runtime (faster-whisper, ctranslate2, torch, onnxruntime, openvino,
#     pyannote.audio, speechbrain, llama-cpp-python, transformers)
#   - numpy, soundfile, librosa, pyaudio, av, soxr, webrtcvad, silero-vad
#   - Redis, Kafka, MinIO, any vector database
# ===========================================================================
